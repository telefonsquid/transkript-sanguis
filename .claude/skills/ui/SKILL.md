# UI

## Decisions

- **Logo:** the wordmark is "Transkript Sanguis" in Fraunces italic 600 (`SOFT` 0, `WONK` 1, optical sizing auto) with a blood drop in place of the dot of the i in Sanguis (the other i keeps its dot) (`Logo.svelte` in `src/lib/ui/`, drop placement in `layout.css`). The placement was measured against the real i in Chromium: the round part of the drop sits on the centre of the dot within about a pixel from 16 to 60 px (it drifts at very large sizes, where optical sizing moves the dot). The drop is `--blood` (darker red on light, brighter on dark and on the light theme's flag chip). With `glint` (the welcome hero only) a highlight inside the drop runs in the five trans flag colours, too thin to read as a flag at a glance. With `flourish` (the hero and the top bar) a pen swash runs close under the wordmark, swelling early and ending in a hairline. Its outline is computed from a centre line and a pressure curve (`brush`), a mask along the centre line draws it in. It sits behind the letters, which carry a stroke in the page colour at 72% under their fill (`paint-order: stroke fill`), so the swash fades at the same distance around every glyph. The halo takes `--logo-ground` (page colour by default, `--surface` in the top bar, `--flag-halo` on the flagged name). The swash draws itself when it mounts and once more on every hover, a hover while it still draws is ignored. Rejected: a drop falling from the swash, rectangles that switch the swash between front and back, a ring around the wordmark, a strike through it. The hero scales with the viewport below `sm` so it never scrolls sideways. The README images in `docs/assets/` come from `scripts/readme.ts` (demo profile Raven, both themes, flag colours of the top bar name hidden so the surprise stays in the app, logo on a transparent ground with the halo in GitHub's page colours), rerun it after visible UI changes. The app icon (`static/favicon.svg`, PNGs from `scripts/icons.ts`) is a Fraunces italic S on the dark square with the drop as its full stop, the S an outline so the icon needs no font. S and drop are centred optically (ink box within a few pixels of the middle, slightly high because the drop weighs the bottom right). Fraunces is self hosted via `@fontsource-variable/fraunces/full-italic.css`, the only file with the optical size axis that gives the large wordmark its contrast. Rejected: Instrument Serif, Bodoni Moda, DM Serif Display, Gloock, a drop only icon, an i only icon (reads as info).
- **Landing page:** `/welcome` opens first once per browser session (`transkript-sanguis:landed` in sessionStorage, set when the page shows), reloads stay where they are. Without that flag, consent or a profile the layout redirects there (`/about` and `/changelog` are exempt, the changelog is linked from the release notes). It has no header, only the floating language, theme and GitHub controls. With an own profile the active one leads as a card with therapy and counts, other own profiles follow as pills, then Manage my data, View demo and New profile. Below them a small About toggle opens two muted, justified paragraphs: an open source app to track and analyze blood tests that keeps all data local, then the hormone therapy support led by the trans flag emoji. The README intro carries the same text. The disclaimer steps run inside the page through `start`, skipped once consent exists.
- **Page loading:** while `navigating.to` is set the layout lays a transparent overlay over everything that swallows clicks and shortcuts. After 120 ms a thin blood red bar with a glowing head runs along the top edge (`Progress.svelte` in `src/lib/ui/`): it rushes to a third, then crawls and never arrives, and once the page is there it runs to the end and fades. It carries its own view transition name so the finish plays over the page change. Under reduced motion it stands still at full width. Rejected: a drop that fills and drains in the middle of a washed out page.
- **Motion:** every animation follows `motion.reduced` (`motion.svelte.ts`), which combines the system setting with `prefs.reduceMotion` (the switch in the theme menu, `AppearanceMenu.svelte`). The layout mirrors it as `data-motion` on `<html>`, where one CSS rule stops all CSS animations and transitions. Svelte transitions run as web animations and ignore that rule, so components import `fade`, `fly`, `slide`, `pop`, `flip` from `motion.svelte.ts`, never from `svelte/transition` directly. Page changes, view tabs and profile switches are view transitions (`navigate`, `morph`), theme and language changes repaint the whole page (`repaint`).

## Conventions

- Therapy tints: flag pink (`--fem`, text `--fem-ink`) and blue (`--masc`, `--masc-ink`) mark feminizing and masculinizing HRT in UI chrome only (avatars, therapy names, the therapy picker), never in charts where colours carry reference kinds. `TINT` in `TherapyName.svelte` maps therapy to text class. The HRT box in the value texts uses the same tints.
- Footer (`AppFooter.svelte`): disclaimer and links on the left (About, Sources, Changelog, GitHub, the other build), on the right the update notice, the desktop update switch, the version and the shortcuts button. 11px `text-ink-3`, links underlined in `--line-strong`, the update notice in `text-ink` underlined in `--blood`.
- Control heights: filter bar controls are `h-7`, top bar controls `h-8`.
- Motion classes in `layout.css`: `rise` (entrance, staggered by `--i`, capped at 16 steps), `rise-row` (fast variant for long tables, capped at 40 short steps so no block of rows pops in late), `appear` (fade, `--delay`, `--dur`), `draw` (chart line with `pathLength="1"`), `dot` (marker pop), `glide` (SVG parts follow scale changes through CSS transitions of `cx`, `y`, `d`, `transform`). SVG lines that must glide are placed by `transform` or drawn as thin rects, because `x1`/`y1` do not transition. Entrance animations use `backwards` fill so they let go once finished.
- Elements with a `view-transition-name` become stacking contexts. The header carries `z-30` so its menus stay above the content.
- Empty date and time inputs and unset selects get the `empty` class (muted until focused), placeholders use `--ink-3`.
