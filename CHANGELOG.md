# Changelog

Every release of Transkript Sanguis. This file is the only place release notes
are written: the app parses it for its [changelog page](https://transkript-sanguis.henkys.dev/changelog)
and CI reads the matching section into the GitHub release, so the shape of the
headings matters.

- One `## <version> — <YYYY-MM-DD>` heading per release, newest first.
- Optional `### Added` / `### Changed` / `### Fixed` groups under it.
- Everything else is plain bullets or short paragraphs.

## 0.1.0 — 2026-09-27

First release, and the first one as a desktop app.

### Added

- Profiles for cis people and for feminizing and masculinizing hormone therapy
- Four demo profiles to look around without entering anything
- Every value charted over time against researched reference ranges, each with its source
- Overview, Compare, Matrix and Table views, and a focus view per value
- Medication timeline laid over the charts
- Manual entry, import through an AI agent of your choice, and backups with the original reports
- English and German, with value names in a second language
- Desktop app for Windows, macOS and Linux, with an opt in check for new releases
